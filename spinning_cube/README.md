# Spinning Cube

**Status: In progress.**

A learning project in C with the goal of rendering a spinning 3D cube in the terminal using ASCII characters.

Inspired by [ASMR Programming — Spinning Cube](https://www.youtube.com/watch?v=p09i_hoFdd0).

The current program experiments with printing characters, clearing the terminal, and moving the cursor. The cube rendering and rotation are not implemented yet.
